Privacy Policy

LAST UPDATED: OCTOBER 23, 2026 (v2.7.1)

Pulse Music is an open-source Android music client. This policy explains what the app stores on your device, which network operations it performs, and what this website does. We do not sell personal data, and the app does not include Firebase Analytics or advertising SDKs.

1. Data Stored on Your Device

Pulse Music works primarily on your Android device. We do not require an account, and we do not operate a server that stores your listening history.

  • Local Library & Offline Storage: Your playlists, favorites, download tasks, settings, and cached tracks are stored locally using Android Room SQLite and the Storage Access Framework. This data is not synced to us.
  • Pure Offline Mode: This mode stops online search and streaming requests and limits playback to local or cached content. It is not a network kill switch. Update checks, downloads you start, and remote configuration or kill-switch requests can still use the network unless you disable those features or restrict network access in Android.

2. Network Operations

Pulse Music is not a zero-network app. It performs network requests when you use online features or when background maintenance is enabled. Those requests necessarily disclose technical information such as your IP address, request time, and user agent to the destination service.

  • Search, streaming, and metadata: Requests go to third-party providers such as YouTube Music, JioSaavn, SoundCloud, and their content delivery networks. Those providers process request data under their own privacy policies.
  • Pulse JAM rooms: Pulse JAM uses Firebase Realtime Database and Firebase Authentication (including anonymous authentication where enabled) to create and join live rooms. Room records can include a room code, participant identifier or display name, track metadata, playback position, queue, and votes. Room data is stored in Firebase while the room exists and may persist until the host ends or cleans up the room, or until it is removed by retention controls. Disconnected participants are pruned from active presence. Google/Firebase processes this data under Google's privacy terms.
  • Downloads and update checks: APK downloads and update checks use GitHub Releases and the GitHub API. Android's package installer handles installation after you confirm it. GitHub receives standard request metadata.
  • Remote configuration and kill-switch: The app may fetch configuration or a kill-switch response to disable broken providers or features. These requests also disclose standard technical information to the configuration host.
  • Third-party providers: The app uses unofficial provider integrations. Those services may log requests or change their practices independently of Pulse Music.

3. Analytics and Advertising

Firebase Analytics has been removed from the app. Pulse Music does not include advertising SDKs, sell personal data, or build advertising profiles. Third-party streaming providers and Firebase may still process technical data as described above under their own policies.

4. This Website

This website is static and does not include analytics. It loads Google Fonts (which sends a request to Google), uses the public GitHub API to display the latest release and developer profile, loads GitHub's button script, and fetches the app changelog from GitHub. The site stores your theme choice and a roughly 10-minute cache of public GitHub API responses in your browser's localStorage. Vercel or GitHub Pages may keep standard server logs. Links to external sites are governed by those sites' policies.

5. Retention and Your Choices

Local app data remains on your device until you clear it or uninstall the app. You can delete downloads and cached files from the app or Android settings, disable automatic update checks where available, and restrict network access with Android's system controls. Pulse JAM room data follows the Firebase retention described above. If you need a room removed, open an issue on GitHub with the room code and approximate time; anonymous rooms may not be identifiable.

6. Children

Pulse Music is not directed at children under 13. Do not use Pulse JAM if you are below the minimum age required by your local law or the applicable provider's terms.

7. Changes to This Policy

We may update this policy as the app changes. Material changes will be reflected by the date and version above.

8. Contact

If you have questions about this policy or how data is handled, open an issue or discussion on the official GitHub repository.
