# Pulse Music
Pulse Music is a modern, open-source Android music player featuring a Neumorphic/Skeuomorphic design. It supports high-fidelity audio streaming, local offline playback, precise live room synchronization (Pulse JAM), and democratic queue controls.

## Key Features
- **Pulse JAM:** Real-time synchronized music rooms for remote listening. Hosts control playback, guests can vote skip, and ExoPlayer timestamp drift is auto-corrected.
- **Dedicated Pure Offline Mode:** Instant zero-network flight mode toggle for playing local and cached music with zero cellular data.
- **Instant Live Download Queue:** Real-time byte streaming download progress and immediate offline queue population for single tracks, albums, and full playlists.
- **Multi-Source Engine:** Aggregates streams and metadata across YouTube Music, JioSaavn, and SoundCloud with seed-provider affinity.
- **Design:** Skeuomorphic UI elements like analog VU meters, LED lamps, and tactile buttons.
- **Version:** Currently v2.7.0
- **Platform:** Android (v2.7.x)
